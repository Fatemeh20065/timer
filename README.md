⏱️ Timer Image Movement Project
Hello everyone! This is a C# project that demonstrates how to move an image using a timer. The program provides several buttons to control the movement, including forward, backward, increase speed, decrease speed, and stop.

✨ Features
Move an image across the screen using a timer.

Forward and Backward buttons to control direction.

Increase Speed and Decrease Speed buttons to adjust movement speed.

Stop button to pause the movement.

Simple and interactive graphical interface.

⚙️ Prerequisites
C# compiler (Visual Studio or .NET SDK).

Windows Forms or WPF environment (depending on implementation).

No external libraries required.

🚀 How to Run
Clone or download the project files.

Open the project in Visual Studio.

Compile and execute the program.

Use the buttons to control the image movement.

📊 Example Output
When the program runs, an image moves across the form.

Clicking Forward moves it to the right.

Clicking Backward moves it to the left.

Increase Speed makes the image move faster.

Decrease Speed slows it down.

Stop halts the movement completely.
